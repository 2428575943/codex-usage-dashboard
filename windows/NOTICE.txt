Codex Quota Guard 0.2.1

This community tool registers a UserPromptSubmit hook and maintains model defaults.
First enablement requires your review in Codex Settings > Hooks. It never writes
approval hashes or bypasses Codex's hook trust checks.

After review, the hook checks the actual selected model before each submission,
including submissions in existing local chats, without restarting Codex. A model
outside the current quota tier is blocked; select an allowed model and resubmit.
Concurrent submissions share at most five seconds of official quota cache.

Already sent requests and internal continuation/retry requests in the same turn
are not intercepted. Disabled, untrusted, failed or timed-out hooks can fail open
in Codex. This preview is not a system security boundary. Effort menu settings
do not enforce existing per-turn effort overrides.

No prompts, transcripts or credentials are saved or uploaded. The tool never
patches Codex.exe, injects processes, or weakens network/security settings.

Software update checks run at most once per day. Signed update verification is
not a Windows publisher signature or a guarantee of antivirus acceptance.

Uninstall restores owned settings and removes only this tool's hook. Backups stay
in %LOCALAPPDATA%\CodexQuotaGuard. Exiting the tray does NOT disable a reviewed
hook; use Disable and restore or disable it in Codex Settings > Hooks instead.
